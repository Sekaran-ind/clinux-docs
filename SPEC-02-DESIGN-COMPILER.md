 # Specification 02: Design-Time AST Parser & YAML Compiler

## 1. Objective
Implement a Node.js automated workflow script that extracts a dictionary of valid FHIR paths from code structures, validates human-authored room configuration templates, and outputs official FHIR Questionnaire resource blueprints.

## 2. Technical Component Requirements

### Component A: TypeScript AST Schema Extractor (`lib/parse-profiles.js`)
- **Input**: A collection of local `.ts` files detailing project-specific FHIR interfaces (e.g., `Patient`, `Observation`).
- **Dependencies**: `ts-morph`
- **Output**: A comprehensive JSON Meta-Schema layout file named `form-schematics.schema.json`.
- **Logic Matrix**:
  - Traverses code declarations to extract deeply nested properties.
  - Flattens attributes into absolute string identifiers (e.g., `Observation.valueQuantity.value`).
  - Matches types down to primitives: string, number, boolean, or specific choice enum arrays.
  - Constructs a validation file ensuring that user-created configuration files can only select paths identified during the code-crawling step.

### Component B: Form Blueprint Validator & Compiler (`lib/yaml-to-questionnaire.js`)
- **Input**: A text configuration template written in YAML format (`form.yaml`) using the schema layout generated by Component A.
- **Dependencies**: `js-yaml`, `ajv`, `ajv-errors`
- **Output**: A production-ready, fully compliant `Questionnaire.json` resource file matching the official HL7 FHIR R4 standard.
- **Validation Rules**:
  - **Structural Check**: Verifies that the configuration file matches all structural parameters mapped out in the core meta-schema definition.
  - **Semantic Check**: Ensures every path defined inside a resource collection actually belongs to that explicit model profile. Throws highly descriptive terminal alerts if paths are typed incorrectly.
- **Compilation Requirements**:
  - Automatically structures elements inside an `item` array.
  - Converts user-declared UI types into valid FHIR property shapes (`decimal`, `string`, `choice`).
  - **Crucial Requirement**: Inject an official FHIR `definition` property for every target field using the absolute extraction pattern string: `http://hl7.org{ResourceType}#{Path}`. This enables automated server-side data processing.
